## OUT-OF-SCOPE FINDINGS

### OOS-D016-CODE-01 — pacing grant vs provider-start gap

Triage: `ACKNOWLEDGED / DEFERRED`

The Durable Object records/grants semantic request-start permission before the actual Worker-to-provider fetch begins, so grant time is not mathematically identical to provider-network start time. The reviewer considered the practical gap non-blocking under the current 1000 ms gate plus the separate <=0.5 req/s broad-enable guardrail.

Revisit trigger: measured staging/production behavior or future higher-capacity requirements show that grant-time serialization no longer provides sufficient margin for the provider's account-wide semantic pacing constraint.

### OOS-D016-CODE-02 — cache stampede

Triage: `ACKNOWLEDGED / DEFERRED`

Existing cache reads/writes are not atomic. Concurrent identical cache misses can therefore produce duplicate provider work. This behavior predates D-016; semantic pacing now bounds semantic starts but duplicate misses may add cost/queue load.

Revisit trigger: staging/production telemetry shows duplicate-miss behavior materially affects provider cost, queue latency, or capacity.
